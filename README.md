## some sounds i took from humphreygaming/survivcustomsoundsandtextures and updated them to work with survev.io and resurviv.biz
# all credit for the sounds goes to humphreygaming, i just made the scripts that put them in the game
###  install
1. get tampermonkey or violetmonkey or any userscript manager.
2. make a new script and paste in the one you want
3. Survevsounds.js for survev.io, Resurvivsounds.js for resurviv.biz
4. save it ctrl + s in the userscript manager go back to survev.io or resurviv.biz and reload the site
